# Productivity Skills

General workflow tools, not code-specific.

## User-invoked

- [grill-me](grill-me/SKILL.md) — Interview the user to sharpen a plan or design.
- [handoff](handoff/SKILL.md) — Compact the current conversation into a handoff document.
- [teach](teach/SKILL.md) — Teach the user a new skill or concept within the workspace.
- [to-questionnaire](to-questionnaire/SKILL.md) — Turn an unresolved decision into a questionnaire.
- [wait-what](wait-what/SKILL.md) — Re-pitch the last message in clearer terms.

## Model-invoked

- [grilling](grilling/SKILL.md) — Grill the user relentlessly about a plan or design.
- [writing-for-agents](writing-for-agents/SKILL.md) — Write effective documents for agents.
