# Thinking And Docs Skills

Clarify decisions, capture ideas, and improve project documentation.

## User-invoked

- [before-building](before-building/SKILL.md) — Fire the moment the user proposes a build. Instantly surface the 1-3 consequential choices hidden in his idea. Can also be invoked with /before-building.
- [decisions](decisions/SKILL.md) — Ask the agent to list all choices it made during the current work that it is not confident of. Manual-only; invoke with /decisions.
- [level-up](level-up/SKILL.md) — Assess technical and product knowledge, record ratings, and create a learning plan.
- [read-all-adrs](read-all-adrs/SKILL.md) — Read every ADR in the project's docs/adr directory.
- [remind](remind/SKILL.md) — Rewrite the last response simpler and shorter in plain English, prefixed with a 3-5 sentence TLDR of the conversation so far. Manual-only, invoked as /remind.
- [short](short/SKILL.md) — Shorten the current answer while preserving its substance.
- [learning-coach](learning-coach/SKILL.md) — Teach the user a new skill or concept, within this workspace.
- [brain-to-docs](brain-to-docs/SKILL.md) — Extract project vision, decisions, and preferences into a README and ADRs through a Q&A process.
- [next-decision](next-decision/SKILL.md) — Resolve open decisions one at a time with options and a recommendation.
- [prompt-me](prompt-me/SKILL.md) — Elicit a project's priorities and open concerns through focused questions.
- [save-idea](save-idea/SKILL.md) — Capture content ideas in the user's video or podcast topic backlog.
